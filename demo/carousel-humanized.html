Pipeline
03 / 06

From user input to financial insight

01 Ingest: Discord/Web/CSV input enters API layer.

02 Parse: GPT-5-mini extracts structured transaction fields.

03 Validate: allowlist guards + duplicate checks.

04 Normalize: fx_history → fx_rates → 1.0 fallback; compute amount_idr server-side.

05 Persist: write transactions/accounts and trigger downstream aggregations.

06 Automate: cron + OpenClaw refresh snapshots, insights, market data, FX rates.

07 Output: KPI cards, portfolio charts, AI widget, Discord confirmations.
